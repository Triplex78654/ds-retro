Télécharger Rétro

Gratuit, sans compte et sans publicité. Les fichiers sont publiés sur la page officielle du projet sur GitHub : télécharge Rétro uniquement depuis là.

Conseillé

Installateur

  • Fichier Retro-<version>-installation.exe (environ 145 Mo).
  • Raccourci dans le menu Démarrer, dossier d'installation au choix.
  • Les nouvelles versions s'installent depuis l'appli.
Télécharger l'installateur
Sans installation

Version portable

  • Fichier Retro-<version>-portable.exe (environ 133 Mo).
  • Se lance directement, sans rien installer (clé USB, PC partagé).
  • Pour changer de version, télécharge la nouvelle à la main.
Télécharger la version portable

Rétro n'est pas encore signé numériquement : au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur ». Clique sur Informations complémentaires, puis Exécuter quand même. Ne le fais que pour un fichier venu de la page officielle des versions.

Configuration requise

Configuration requise

ÉlémentMinimum
SystèmeWindows 10 ou Windows 11, 64 bits
Espace disqueEnviron 400 Mo pour Rétro une fois installé, plus la place des émulateurs que tu utilises et de tes jeux
Connexion InternetPour télécharger un émulateur au premier jeu d'une console et pour les mises à jour. Le jeu lui-même n'en a pas besoin.
Manette (facultatif)Xbox, PlayStation, Switch Pro ou toute manette reconnue par Windows

NES, Super Nintendo, N64, PlayStation et DS fonctionnent sur la plupart des PC. 3DS, Switch, PS2 et PS3 demandent un PC plus puissant : la puissance nécessaire dépend de l'émulateur, consulte sa page officielle (liens dans Ressources officielles).
