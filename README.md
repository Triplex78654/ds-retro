# ds-retro

Émulateur Nintendo DS dans le navigateur, base d'une future Activité Discord.

- Fonctionne sur PC et mobile (manette tactile sur iPhone/Android).
- Émulateur : [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) (GPL-3), cœur DeSmuME, chargé depuis le CDN officiel.
- Le jeu choisi reste sur l'appareil du joueur : rien n'est envoyé ni stocké sur ce dépôt.
- Aucun jeu ni BIOS Nintendo n'est inclus. Utilise des homebrew gratuits ou une copie de ta propre cartouche.

Site : https://triplex78654.github.io/ds-retro/
