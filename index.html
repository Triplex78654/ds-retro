Charger un jeu

Choisis un fichier .nds sur ton PC. Il reste sur ton appareil : rien n'est envoyé sur un serveur.

Glisse ton fichier ici, ou

Commandes par défaut

  • Croix directionnelle : ↑ ↓ ← →
  • A / B / X / Y : X Z S A
  • Start / Select : Entrée Maj
  • Écran tactile : clic de souris sur l'écran du bas
  • Les touches et la manette se règlent dans le menu de l'émulateur (icône manette).

Des jeux à tester légalement

Utilise des jeux homebrew gratuits (beaucoup sur itch.io en cherchant « Nintendo DS homebrew ») ou une copie de ta propre cartouche que tu as extraite toi-même.
